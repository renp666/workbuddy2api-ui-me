### race 门禁的环境差异

本机（Windows）无任何 C 编译器（gcc/clang/zig 均不存在，WSL 无发行版），`go test -race` 报 `-race requires cgo` 无法执行。改在本地已有 `golang:1.23` 镜像的 Linux 容器内执行（console 模块 go 1.22.5，无第三方依赖，`GOPROXY=off` 离线可跑）：

```bash
docker run --rm -e GOFLAGS=-mod=mod -e GOPROXY=off \
  -v <repo>/console:/src -w /src golang:1.23 bash -c "go test -race ./..."
# ok  workbuddy2api-console  15.307s
```

仅挂载源码目录运行测试，未触碰部署、compose、密钥与任何运行中容器。

## 二、实现摘要

- **任务 1 冷却阶梯**：`cooldownLadder = {30s, 2m, 10m, 30m}` + `ladderCooldown(ejections)`；`retryAfterCooldown(retryAfterSec, ejections)` 头优先（封顶 30m）、无头走阶梯；`Ejections` 落盘（`ejections`），完全恢复归零。
- **任务 2 半开收紧**：新增 `routeGate()` 试探租约（`probes` 表 + `probeLeaseTTL` 兜底），挂 `resolveEntryChain` 逐跳过滤处；观察态失败立即回熔断并升一档；连续 `observeSuccessThreshold=2` 次成功完全恢复；新增 `observeMaxWait=5min` 静默恢复兜底（低流量目标防静默排除）；新增 `unavailable()`（Open 或 Observing）供整批目的地选择。
- **任务 3 摘链保护**：apply 改写分支统计可用候选（经 `unavailable` 过滤），剩余=1 时禁摘 + P1 告警 `circuit_last_candidate`；3-strong 禁摘、`routes.bak`、落盘回放全部保留。
- `blocked()` 语义未动（仅 Open），`retry_test.go` 全量通过验证兼容。
