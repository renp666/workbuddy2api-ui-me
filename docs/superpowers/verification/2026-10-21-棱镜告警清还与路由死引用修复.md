# 棱镜告警清还与路由死引用修复验收记录（2026-10-21）

> 触发：AgentFlowMe 看板 `gofishmaster` 积压 17 张 `[P1][棱镜]` 告警卡，用户指令「清还」
> 环境：Windows 本机；棱镜网关 `127.0.0.1:7863`（console + core 容器同网络）；
> `runtime/wb2api/console/routes.json` 是**运行时数据**（`runtime/` 已被 `.gitignore` 排除），
> 本仓只记录改动事实与验证读数，不把运行时文件入库。

## 一、告警卡积压构成

| rule | 数量 | 说明 |
|---|---|---|
| `pin_error` core `1-daily-v1` | 3 | 账号被 pin，候选链取不到账号 |
| `circuit_open` opencode `1-daily-v1` | 4 | 回退链在 opencode 一侧熔断 |

| **合计** | **17** | 见第五节归档清单 |

## 二、根因一：core 账号 pin（已清）

**现象**：`GET /admin/pin` 显示 `cn`、`global` 两个 realm 均被钉；core 侧 `/app/data/pin.json` 同一记录。
`1-daily-v1` 主候选在 core（`global:deepseek-v4.1-flash`），被 pin 后候选链整体不可用，
下游表现为 `503 pinned_account_unavailable`，并触发 opencode 回退链的连锁告警。

**处置**（console 管理会话，需 CSRF）：

```
POST /admin/login      {"key": "<admin_key>"}          → Set-Cookie + csrf
POST /admin/unpin      {"realm": "cn"}
POST /admin/unpin      {"realm": "global"}
```

**验证（清后现读）**：

| 位置 | 读数 |
|---|---|
| `GET /admin/pin` | `{"pins": {"cn": null, "global": null}}` |
| core 容器 `/app/data/pin.json` | `{}` |

## 三、根因二：`routes.json` 指向已下架的 opencode free 模型（已修）

opencode free 池换血后，`GET /admin/opencode` 现役 8 个模型：

```
opencode-OC · Big Pickle                 opencode-OC · MiMo-V2.6-Flash Free
opencode-OC · GLM-5.3-Flash Free         opencode-OC · MiniMax M3.1 Flash Free
opencode-OC · LongCat 2.5 Preview Free   opencode-OC · Nemotron 3 Ultra Free
opencode-OC · Nemotron 3.5 Lightning      opencode-OC · Nemotron 3.5 Super VL Free
```

而别名表里仍在引用两个**上游已不再提供**的模型，调用一律
`model_not_found: Select an available free model from /v1/models`。

**死引用与重指**（备份：`runtime/wb2api/console/routes.json.bak-20261021-103544`）：

| 别名 | 位置 | 原值（死） | 现改为 |
|---|---|---|---|
| `5-free-v1` | 主目标 | `opencode-OC · Space Bunny Free` | `opencode-OC · GLM-5.3-Flash Free` |
| `5-free-v1` | 回退 1/2 | `MiMo-V2.6-Flash Free` / `GLM-5.3-Flash Free` | `MiMo-V2.6-Flash Free` / `MiniMax M3.1 Flash Free` |
| `5-free-v2` | 主目标 | `opencode-OC · DeepSeek V4.1 Flash Free` | `opencode-OC · MiMo-V2.6-Flash Free` |
| `5-free-v2` | 回退 | （无） | `MiniMax M3.1 Flash Free` / `Nemotron 3 Ultra Free` |
| `4-max-v2` | 回退 1 | `opencode-OC · Space Bunny Free` | `opencode-OC · MiniMax M3.1 Flash Free` |

**写入方式**：`POST /admin/route/save`（整表回写；console 内存快照与磁盘文件同时原子替换，
无需重启容器）。`console/route.go` 的 `save()` 显式把 `disabled_models` / `enabled_models`
原样带入，因此一次别名保存不会清空模型开关表。

**改动面复核（保存后现读）**：

| 项 | 保存前 | 保存后 |
|---|---|---|
| 别名条数 | 12 | 12 |
| `overrides`（开关表覆盖） | 99 | 99 |
| `model_costs` | 18 | 18 |
| `disabled_models` | 67 | 67 |
| `enabled_models` | 32 | 32 |
| `auto_fallback` | `global:deepseek-v4.1-flash` | 同前（未改） |
