三个硬伤：

③ 明度差只有 0.049 —— 四张卡并排时几乎同一亮度，缺少层次。

我的推荐：D

理由三条：

① 最小色相间距 65°，是四套里最大的（现状只有 24°）。表格里并排出现时，一眼能分清谁是谁 —— 这正是「一束色」存在的意义。

② 琥珀色避开了状态红。方案 B 的 OpenCode 是正红 #CE2617，和你的 --danger #c22f3c 挨太近，"通道色"和"故障色"会混淆。D 用 #AF4D17 橙，语义干净。

③ 暖色锚点解决了"糊在一起"。现状四个色全在冷色半区（217°–360°），没有节奏。D 的 45° 琥珀把冷暖对比拉开，整排读起来有起伏。
