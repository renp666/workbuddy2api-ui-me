## 1. 为什么现在这组配色「不好看」（数据诊断）

把现有四通道色转成 OKLCH 拆开：

| 通道 | 本色 | OKLCH | 色相 |
|---|---|---|---|
| WorkBuddy | `#4f52d6` | L .516 · C .198 | **276°** |
| Zcode | `#0a7f96` | L .551 · C .096 | 217° |
| Qoder | `#7a3fc4` | L .512 · C .197 | **300°** |
| OpenCode | `#c4356f` | L .561 · C .184 | 1° |

**三个硬伤：**

1. **色相挤在 24° 内** —— WorkBuddy(276°) 和 Qoder(300°) 明度几乎相同（.516 / .512）、彩度几乎相同（.198 / .197）。表格里并排出现，眼睛分不出谁是谁。「一束色」的意义就是一眼认通道，现在这个前提不成立。
2. **四个色相全在冷色半区**（217°–360°），缺暖色锚点，整排"糊"。
3. **明度差仅 0.049**，四张卡并排几乎同一亮度，缺层次。

> 注意：现有配色的**对比度是达标的**（文字版 5.28–7.40:1，全部 ≥AA）。问题不在无障碍，在**辨识度**。

## 2. 四套候选（已实测 WCAG）

| 方案 | 色相分布 | 最小间距 | 对比度 | 特点 |
|---|---|---|---|---|
| **A** 微调 | 215 / 272 / 320 / 358 | 38° | AA 全达标 | 改动最小，Qoder 偏洋红 |
| **B** 均匀四分 | 30 / 195 / 255 / 315 | 60° | AA 全达标 | 区分最强，但 OpenCode 正红与 `--danger` 混淆 |
| **C** 低彩度灰调 | 25 / 210 / 268 / 330 | 55° | AA 全达标 | 安静耐看，但"一束色"识别性变弱 |
| **D** 高区分 ⭐ | 45 / 190 / 255 / 320 | **65°** | AA 全达标 | 区分度最高 + 暖色锚点 + 避开状态红 |

**推荐 D**，三条理由：

1. **最小色相间距 65°**，是四套里最大的（现状 24°）。表格并排时一眼分清——这正是「一束色」的目的。
2. **琥珀 `#AF4D17` 避开状态红**。B 方案的 OpenCode 是正红 `#CE2617`，和 `--danger #c22f3c` 挨太近，通道色与故障色会混淆。
3. **暖色锚点解决"糊"**。D 的 45° 琥珀把冷暖对比拉开。

对比现状**全部提升**（现状最低 5.28:1 → 现在最低 7.42:1）。

### 3.3 谱线渐变需同步调整

`--spectrum` 是按色相排的（靛→紫罗兰→青→玫红），换色后顺序要改为按新色相：

```css
/* 现有：靛(276)→紫罗兰(300)→青(217)→玫红(1)  -- 顺色相才读成一道连续的光 */
/* 新色相：zcode 190 → workbuddy 255 → qoder 320 → opencode 45 */
--spectrum:linear-gradient(90deg,var(--ch-zcode) 0%,var(--ch-workbuddy) 34%,var(--ch-qoder) 67%,var(--ch-opencode) 100%);
--spectrum-v:linear-gradient(180deg,var(--ch-zcode) 0%,var(--ch-workbuddy) 34%,var(--ch-qoder) 67%,var(--ch-opencode) 100%);
```

⚠️ **顺序变了**：原来是 workbuddy 打头，现在是 zcode 打头。若 `app.js` 里有依赖通道顺序的逻辑（如 `usageChannelOrder`），需同步核对。

## 4. 配套建议：主色是否跟着调？

现有主色 `--accent:#5b4bf0`（棱镜紫）。方案 D 的 WorkBuddy 是蓝 `#186DCB`，两者不同源。

**三个选项：**

| 选项 | 做法 | 效果 |
|---|---|---|
| **保持紫**（推荐） | `--accent` 不动 | 棱镜品牌标识保留；通道色与主色是两个体系，各司其职 |
| 跟随通道 | `--accent` 改为 `#186DCB` | 全站统一，但丢掉「棱镜紫」这个已有识别 |
| 折中 | 主色改 `#5b4bf0` → `#4f46e5` 微调 | 降低与通道紫的撞色感 |

⚠️ 保持紫的话，通道 qoder（`#A720C2` 品红紫）和主色 `#5b4bf0` 仍有一定接近。**这一点在方案 D 里已经缓解**——现状 qoder 是 `#7a3fc4`，比主色更偏红紫；新配色 `#A720C2` 更偏品红，区分更开。
