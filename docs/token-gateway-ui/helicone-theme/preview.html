值得注意的几个非标准设计

令牌Helicone 的做法为什么这么设计
--card深色下是 hsl(229 84% 5%)，比 --background 亮一档纯黑背景上卡片没有边界，靠亮度差浮起来比阴影有效
--subduedshadcn 没有这个变量，Helicone 独有做三级信息层级：foreground → muted-foreground → subdued-foreground
--confirmative绿色系成功态，深浅两套亮度差很大状态色独立成体系，不复用 Tailwind 的 green-*，避免和图表色打架
--ring浅色=前景色(深)，深色=浅色焦点环要能看见但不抢戏，所以取"反色"而非主色
--radius0.5rem，比 shadcn 默认小小圆角 = 更紧凑、更像工程工具
侧栏宽度12rem (192px)，不是常见的 240pxHelicone 侧栏还有搜索框 + 分组标签，192px 刚好不浪费横向空间
chart-1..10oklch 色彩空间，深色模式整体降亮度 ~0.2同一组色值在深浅两种背景下都能保持可辨识度

怎么用到你的项目里

① 把 helicone-tokens.css 的内容合并进你的 globals.css（或直接替换 @layer base 部分）。
② tailwind.config.ts 直接覆盖，重点是 colors 和 darkMode: ["class"]。
③ 组件层面把 shadcn 的 button.tsx / sidebar.tsx 换成 Helicone 版本，它们依赖的 variant 名已对齐。
④ 装依赖：npm i tailwind-scrollbar tailwindcss-animate @tailwindcss/typography class-variance-authority lucide-react
